years building enterprise web applications in production, mostly in TypeScript: Angular from
version 13 to 20 at work and 22 in my own projects, with Angular Material, PrimeNG and RxJS.
Frontend first, but I can follow a feature from the API endpoint to the UI interface. Node and Express go back to

I spent those years in IT consulting, across the development cycle from estimates to release,
on enterprise projects that went from banking to infrastructure monitoring on geospatial
systems. What they had in common:

- requirements and internal processes turned into scenarios, features and use cases;
- authentication and authorization with access based on roles and profiles, sometimes several
  per user;
- local and remote state across frontend–backend integrations: dashboards, editors, control
  panels, conditional widgets;
- frontend libraries such as Leaflet, for interactive maps over geospatial data.

Right now I'm building personal projects to put into practice what I study, React and Motion
above all, and to bring AI-assisted development into my workflow, with agents that follow my
conventions.

I love this work, and the way AI is changing it fascinates me. I spend a lot of my time
